# 优化方案与路线（草案）

## 目标定位

把「灰原哀工作台」从"有角色的装饰主题"改造成**长期日常可用的克制高级版**：
保留角色元素与身份感，但默认存在感降低；视觉细节（配色/层级/排版/对比度）打磨到位；顺手修掉 `0.2.1-rc.3` 兼容缺口。

## 方向清单

### A. 更克制（默认值收敛）
- [x] 默认「展示强度」从 `clear` 改为 `soft`
- [x] 「减少动态效果」默认开启（标题点线动效默认关）
- [x] 浏览器标题后缀与 favicon 默认恢复原生（本版直接移除投影，C 阶段再做开关）
- [x] 首页立绘/分镜默认透明度调低，hover 才完整显示（可选开关留待 C）

### B. 更精致（视觉质量）
- [x] 调色板复核：正文/次要文字对比度达到 WCAG AA；中性色统一为单一冷紫色相并降低饱和度
- [x] 层级/圆角/阴影/间距统一为单一尺度表（本地 `--wb-radius-*` / `--wb-space-*` / `--wb-shadow-*`）
- [x] 深色模式一致性：明暗 token 重新配对，悬浮/选中/滚动条色阶统一
- [x] 字体尺度与字重统一；中文字标与 `Ai Haibara` 签名比例收敛到 typography 角色层
- [x] 滚动条/选中态/悬浮态状态色统一（新增主题色 `::selection`）

### B2. 热门开源项目借鉴（1.4.0-custom.2 已落地）
- [x] 参考 Claude Style / Open Sea / Dream Skin / Endfield / Catppuccin，只读调研、不复制代码素材
- [x] 弥散环境光（画布/会话/侧栏/Hero 光晕）
- [x] 玻璃薄层（输入卡/会话页头；避免 backdrop-filter 的 fixed containing-block 风险）
- [x] 分层阴影与主题化焦点环（`--dsw-elevation-*`、`--dsw-focus-ring-color`）
- [x] 菜单玻璃收敛与设置项强度可视化（三段强度条）
- [ ] 进阶：侧栏选中态强调条、消息入场动效（需更细的宿主 DOM 适配）

### C. 更可调（设置项）
- [ ] 预设切换：极简 / 标准 / 装饰（一次写入多字段）
- [ ] 插画：开关、位置（首页/页头/边栏）、透明度
- [ ] 主题色可选：冷紫（现有）/ 灰蓝 / 无彩
- [ ] 浏览器标签：可选恢复主题后缀 / favicon
- [ ] 设置项持久化与迁移（沿用现有 configForms 机制）

### D. 兼容 `0.2.1-rc.3`
- [x] 补全语义 token：89/113 design-platform；其余功能性宿主语义保留官方默认并有测试名单
- [x] rc.3 DOM 适配（hero previewBadge、插件页 data-plugin-panel、page-margin 留白、`main.*` outlet）
- [x] 打包 metadata：`engines.dsh` / peerDependencies 加 `0.2.1-rc.3`（摆脱豁免）

### E. 瘦身/性能
- [ ] 素材转 WebP，首页立绘 858KB → 目标 <300KB
- [ ] 动效降级：`prefers-reduced-motion` 全覆盖

### F. 工程
- [ ] CHANGELOG 记录本地改动；README 增加本地分支说明
- [ ] 测试：沿用 `node:test`，补 token 覆盖与设置项用例
- [ ] 版本号策略：`1.4.0-custom.N`

## 第一版建议范围

A + B + D（不加新设置项，只改默认值与视觉细节），验收后再做 C/E。

## 验收清单（每次安装后）

1. 首页：立绘/分镜位置、明暗切换、无装饰模式
2. 会话页：正文/代码块/表格/引用/工具结果可读性
3. 插件页/设置页：页头装饰不遮挡控件
4. 侧栏：图标、选中态、hover、滚动条
5. 浏览器标签：标题与 favicon 表现
6. 卸载/停用：界面完整恢复官方默认
7. `0.2.1-rc.3` 控制台无报错
